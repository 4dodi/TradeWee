📊 Google Sheets — rapports d’analyse

Enregistrez vos analyses dans votre propre feuille Google Sheets : une ligne par analyse (biais, niveaux, textes). Aucun projet Google Cloud n’est nécessaire.

✅ Connecté à · Ouvrir la feuille ↗

  1. Créez une nouvelle feuille Google Sheets ↗
  2. Dans la feuille : Extensions → Apps Script. Effacez le code d’exemple, collez le script, puis enregistrez.
  3. Déployer → Nouveau déploiement → ⚙️ Application Web. Exécuter en tant que : Moi. Qui a accès : Tout le monde. Cliquez sur Déployer, autorisez l’accès, puis copiez l’« URL de l’application Web ».
  4. Collez l’URL ci-dessous et cliquez sur Connecter.

Lors de l’autorisation, Google affiche « Google n’a pas validé cette application » : c’est normal pour un script personnel. Cliquez sur Paramètres avancés → Accéder au projet. « Tout le monde » permet à Tradewee d’écrire dans la feuille sans connexion Google ; seul le jeton secret inclus dans le script l’autorise.

📈 Plans sur votre graphique TradingView

TradingView ne permet pas aux applications externes de dessiner sur votre graphique. Installez une seule fois l’indicateur « Tradewee Levels » : il suffit ensuite de coller vos plans dans ses paramètres, et il affiche celui qui correspond au symbole du graphique.

  1. Copiez l’indicateur, puis dans TradingView : Pine Editor → nouvel indicateur → collez → « Add to chart ». Enregistrez-le.
  2. Copiez vos derniers plans (le plus récent pour chaque actif, 20 max).
  3. Sur le graphique : paramètres de Tradewee Levels (⚙️) → collez dans « Plans » → OK.

📡 Alertes TradingView → analyse automatique

Une alerte TradingView peut lancer une analyse dans Tradewee. TradingView n’envoie pas d’image : l’IA travaille à partir des données de l’alerte (prix, message) et, pour les cryptos, des 60 dernières bougies Binance. Les analyses reçues apparaissent dans l’historique avec 📡.

TradingView ne peut joindre qu’une adresse publique en HTTPS (port 443) : hébergez l’app en ligne ou utilisez un tunnel (ex. Cloudflare Tunnel). Les webhooks nécessitent un abonnement TradingView payant et la double authentification.

Remplacez « Describe your signal » par la description de votre signal (ex. « RSI sous 30 sur H4 »). Le secret empêche quiconque d’autre de lancer des analyses : ne le partagez pas. L’alerte de test lance une vraie analyse (consomme votre quota IA).

⚠️ Avertissement

Tradewee est un outil éducatif. Les analyses générées par IA sont indicatives et peuvent être erronées : une IA peut mal lire un graphique. Le trading comporte un risque de perte en capital.
